# **App Name**: ItemSentry Pro

## Core Features:

- User Authentication & Profile: Secure user registration, login, and profile management with support for different roles (User, Staff, Admin).
- Role-Based Access Control (RBAC): Implement and enforce distinct permissions for User, Staff, and Admin roles, controlling access to features and data.
- Lost Item Reporting: A user-friendly form interface for individuals to submit detailed reports of lost items.
- Found Item Registration: A dedicated interface for Staff members to log and detail items that have been found.
- Item Listing & Search: Dynamic listings and robust search capabilities allowing users and staff to find lost and found items based on various criteria.
- Claim Process & Verification: A structured workflow enabling users to make claims on found items, with a module for staff to review and verify claims.
- AI Description Assistant Tool: A generative AI tool to assist users and staff in crafting clear, concise, and comprehensive descriptions for lost and found items.

## Style Guidelines:

- Primary brand color: A deep, professional blue (#2374CC) conveying trust and clarity. This color will be used for interactive elements, headlines, and key branding accents.
- Background color: A subtle, desaturated light blue-gray (#EBF1F7) providing a clean and serene backdrop for content and forms.
- Accent color: A bright and uplifting sky blue (#41ACCF) used sparingly for notifications, highlights, and elements that require immediate attention.
- Main font: 'Inter', a neutral and highly readable sans-serif, suitable for both headlines and body text to maintain a modern and efficient aesthetic.
- Use a consistent set of clean, line-based icons that clearly represent actions and categories, supporting intuitive navigation.
- Emphasize clear spatial organization with ample whitespace. Design for responsiveness, ensuring functionality and readability across various device sizes.
- Incorporate subtle and functional animations for user feedback on actions, form submissions, and transitions between views, enhancing the sense of a responsive system.
